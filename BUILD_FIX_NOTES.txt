DreamShareLite 0.4.0 - Authentication Session Fix

Fixed an immediate-login logout loop in Source/DreamClient.cpp.

Root cause:
- After login, pull() called the authenticated social_list action directly through http().
- That request did not include the current user's token.
- The Worker correctly returned HTTP 401/code=auth.
- http() interpreted that as an expired token, deleted the saved session, and the UI returned to login.

Fixes:
1. social_list now sends the current user + token.
2. audio_part_b64 WAV upload requests now also send the current user + token.
